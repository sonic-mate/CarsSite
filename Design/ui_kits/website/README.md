# Vostok AutoImport — Website UI Kit

High-fidelity recreation of the marketing website. Premium, dark-accented light theme. Everything is a click-through prototype — interactions are cosmetic, not real.

## Screens
1. **Home** — hero with car search, country tabs, featured catalog, calculator teaser, process, stats, contact.
2. **Catalog** — filter sidebar + grid of car cards.
3. **Car detail** — gallery, specs table, financing, sticky call CTA.
4. **Calculator** — step-by-step price breakdown.
5. **Process / How we work** — 5-step timeline.

## Files
- `index.html` — entry point with screen-switcher (acts as click-through prototype host).
- `Header.jsx`, `Footer.jsx` — global chrome.
- `Home.jsx`, `Catalog.jsx`, `CarDetail.jsx`, `Calculator.jsx`, `Process.jsx` — screens.
- `components.jsx` — shared atoms (Button, Badge, CarCard, Icon, etc).
- `data.js` — fake catalog data.

## Tweaks exposed
- Theme — light / dark
- Density — comfortable / compact
- Accent — wine / gold-led / carbon

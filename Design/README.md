# Восток АвтоИмпорт — Design System

> Премиум, сдержанный, тёмный. Импорт автомобилей из Японии, Китая и Кореи.

---

## О компании

**Восток АвтоИмпорт** — компания, специализирующаяся на подборе, покупке и доставке автомобилей из Японии, Китая и Кореи. Ключевые ценности: **лучшие предложения на рынке, высокий уровень сервиса, надёжность**.

Главная задача сайта — чтобы пользователь **легко нашёл автомобиль и позвонил по номеру `8 800 101 29 18`**. Это означает: понятная навигация, быстрый поиск/каталог, прозрачный калькулятор стоимости, и крупный, всегда заметный CTA с телефоном.

### Источники
Дизайн-система создана **с нуля**, без опоры на существующий код, Figma или брендбук. Все визуальные решения — предложения, требующие подтверждения от заказчика.

---

## Краткое описание визуального языка

- **Тёмный премиум-фон** (близкий к Lexus / Genesis), с глубоким графитовым основным цветом.
- **Светло-золотой акцент** для CTA, цены, ключевых выделений.
- **Премиум-гротеск с характером** для заголовков (узкий, плотный, контрастный — в духе PP Neue Machina / Druk Wide).
- **Чистый нейтральный гротеск** для тела текста.
- **Тонкие границы 1px**, минимум скруглений (4–8px), точечные тени.
- **Реалистичные фото авто** на чёрном фоне с лёгким виньетированием — главный визуальный носитель.

## Content Fundamentals

### Голос и тон
**Уверенный профессионал, без снобизма.** Мы знаем рынок и говорим коротко, по делу. Не «впариваем» — даём факты, цифры и сроки. Где можно сэкономить слова — экономим.

- **«Вы», не «ты».** Уважительное обращение по умолчанию: «Подберём для Вас», «Свяжемся в течение часа». Вне форм — допустима форма «вы» со строчной буквы в текстах статей/блога.
- **Активный залог.** «Привезём из Японии за 45 дней», а не «Автомобиль будет привезён».
- **Конкретика > абстракция.** «Доставлено 1 247 авто» лучше, чем «Большой опыт».
- **Без жаргона аукционов.** Если используется термин (например, «оценка R 4.5», «РОСС RU»), он сопровождается коротким пояснением.

### Casing
- **Заголовки H1–H2:** ВЕРХНИЙ РЕГИСТР для коротких ударных формулировок («АВТО ИЗ ЯПОНИИ ПОД КЛЮЧ»). Это контрастный приём, работает только с премиум-гротеском, не злоупотреблять (≤6 слов).
- **Заголовки H3–H4:** Sentence case («Как мы работаем»).
- **Кнопки:** Sentence case, без точки. («Подобрать авто», «Позвонить», «Рассчитать стоимость»).
- **Метки/категории:** ВЕРХНИЙ РЕГИСТР с трекингом +0.08em («ЯПОНИЯ», «СЕДАН», «ХИТ»).
- **Цены:** разделитель тысяч — неразрывный пробел, валюта — символ «₽», без пробела перед знаком при компактной верстке. («2 350 000 ₽»).

### Эмоджи и пунктуация
- **Эмоджи не используются** в интерфейсе и маркетинге. Бренд серьёзный.
- **Длинное тире** — разделитель в подзаголовках («Япония — Китай — Корея»).
- **Кавычки-ёлочки** «...» в основном тексте; внутри — „...".
- **Неразрывные пробелы** перед единицами: «45 дней», «2 350 000 ₽», «8 800».

### Примеры копирайта

✅ **Хорошо:**
- «АВТО ИЗ ЯПОНИИ, КИТАЯ И КОРЕИ — ПОД КЛЮЧ»
- «Доставка 35–55 дней. Все расходы прозрачны.»
- «Рассчитайте стоимость или позвоните: 8 800 101 29 18»
- «1 247 авто доставлено за 8 лет работы»

❌ **Плохо:**
- «🔥 ЛУЧШИЕ АВТО ИЗ ЯПОНИИ!!!» (эмоджи, восклицания, гиперболы)
- «Мы — команда профессионалов с многолетним опытом» (вода)
- «Закажи свою мечту прямо сейчас!» (фамильярность, продающий тон)

### Числа доверия (используются на главной)
- **1 247** доставленных авто
- **8 лет** на рынке
- **3 страны** прямого импорта
- **45 дней** средний срок «под ключ»

*(Цифры — плейсхолдеры; уточнить у заказчика.)*

## Visual Foundations

### Палитра
**Базовая идея:** тёплый off-white фон + глубокий чёрный текст + бордовый/винный акцент. Это направление **«Дорогой светлый»** (вариант 2 из предложенных). Тёмная версия — как опция.

#### Нейтральная шкала (основа интерфейса)
| Токен | HEX | Применение |
|---|---|---|
| `--ink-100` (Off-white Paper) | `#F5F3EE` | Основной фон страницы |
| `--ink-95` | `#EDEAE2` | Поверхность секций / hover светлых элементов |
| `--ink-85` | `#D4CFC2` | Разделители, рамки |
| `--ink-60` | `#8A8478` | Второстепенный текст, метки |
| `--ink-30` | `#3A3833` | Заголовки на светлом (мягче чем чистый чёрный) |
| `--ink-10` (Carbon) | `#0F1115` | Основной текст / тёмные секции |

#### Акценты
| Токен | HEX | Применение |
|---|---|---|
| `--accent` (Wine) | `#8A2B2B` | CTA, цены, фокус-кольцо, активные состояния |
| `--accent-hover` | `#6F1F1F` | Hover для CTA |
| `--accent-soft` | `#F0E4E4` | Лёгкий бэкграунд для тегов «Хит», цен на карточках |
| `--gold` (Sand Gold) | `#C8A45C` | Декоративный акцент: разделители, метки «PREMIUM» |

#### Семантика
| Токен | HEX |
|---|---|
| `--success` | `#2F6F4F` |
| `--warn` | `#B07A1A` |
| `--danger` | `#8A2B2B` (= accent) |
| `--info` | `#3A3833` |

### Типографика

**Заголовки (Display):** *Unbounded 600* — премиум-гротеск с полной поддержкой кириллицы, характерный, в духе PP Neue Machina / Druk Wide. Бесплатный (Google Fonts), от ContrastFoundry.
**Подзаголовки (Heading):** *Manrope 700/800* — современный гротеск, ровный, премиальный.
**Текст (Body / UI):** *Manrope 400/500/600* — те же штрихи, единый ритм с заголовками.
**Цифры/моноширинный (Mono):** *JetBrains Mono* — для VIN, цен в таблицах, технических данных.

> ⚠️ **Замены шрифтов.** Пользователь не предоставил шрифты. Unbounded и Manrope — бесплатные Google Fonts с полной поддержкой кириллицы. Ближайшие к платным PP Neue Machina / Söhne. **Ask:** прислать корпоративные TTF/WOFF или подтвердить эти Google Fonts.

### Сетка и отступы
- **Контейнер:** max-width `1280px` + 24px gutter (mobile) / 48px (desktop).
- **Колонки:** 12-колоночная сетка с gap 24px.
- **Spacing scale (4px base):** `4, 8, 12, 16, 24, 32, 48, 64, 96, 128`. Токены: `--s-1` … `--s-10`.
- **Vertical rhythm секций:** 96–128px между крупными секциями на десктопе, 64–80px на мобильном.

### Радиусы
Минимальные. Премиум подразумевает прямые линии.
- `--r-xs: 2px` (бейджи, чипы)
- `--r-sm: 4px` (кнопки, инпуты)
- `--r-md: 8px` (карточки)
- `--r-lg: 12px` (модалки)
- `--r-pill: 999px` (только для тегов фильтров)

### Тени и elevation
Тени **точечные и низкоконтрастные**, никаких диффузных «soft drop shadows».
- `--shadow-1` карточка покоя: `0 1px 0 rgba(15,17,21,0.04), 0 1px 2px rgba(15,17,21,0.06)`
- `--shadow-2` карточка hover: `0 2px 0 rgba(15,17,21,0.04), 0 8px 24px -8px rgba(15,17,21,0.12)`
- `--shadow-3` модалка: `0 24px 64px -16px rgba(15,17,21,0.24)`
- `--inner` фокус: `inset 0 0 0 1px var(--accent)`

### Границы
- **1px solid** в 95% случаев. `--ink-85` для светлой темы.
- **Hairline divider:** 1px `--ink-85` с alpha 60%.
- **Upgrade-граница:** 1px `--gold` для золотых выделений (не злоупотреблять).

### Backgrounds
- **Фон страницы:** ровный `--ink-100`. Без градиентов, без шума, без паттернов.
- **Тёмные секции (hero, CTA-блоки):** ровный `--ink-10`, поверх — фото авто с лёгким радиальным виньетированием от центра. Никаких пурпурных градиентов.
- **Фото-карточки авто:** студийный чёрный фон, авто крупно, лёгкий пол-рефлекс.
- **Полнобличные (full-bleed) фото** — только в hero и в карточке авто (галерея).

### Анимации
**Принцип:** «дорогая машина закрывает дверь — уверенно, мягко, без скрипа». Всё — easing `cubic-bezier(0.2, 0.8, 0.2, 1)` (custom «luxe»).

- **Длительности:** микро 120ms, стандарт 200ms, переходы секций 320ms, hero-параллакс 600ms.
- **Никаких bounce'ов.** Никакого spring overshoot.
- **Hover карточек:** легкий lift (translateY -2px) + усиление тени, 200ms.
- **Hover ссылок:** opacity 0.7 → 1.0, или underline thickness 1px → 2px.
- **Появление при скролле:** opacity 0→1 + translateY(12px→0), 320ms, stagger 60ms.
- **Hero фото:** медленный zoom-in (scale 1.0 → 1.04) на 8s в loop.

### Состояния
- **Hover:** карточки — `--shadow-2` + lift; ссылки — `--accent`; кнопки — `--accent-hover`.
- **Press:** scale(0.98) + быстро вернуться. Длительность 80ms.
- **Focus-visible:** `outline: 2px solid --accent; outline-offset: 2px`. Никогда не убирать!
- **Disabled:** opacity 0.4, без курсора, без hover.
- **Loading:** скелетоны — ровный `--ink-95`, без анимации shimmer (премиум = тишина).

### Прозрачность и блюр
- **Sticky header:** при скролле — фон `rgba(245,243,238,0.85)` + `backdrop-filter: blur(12px)` + 1px нижняя граница.
- **Модалки:** оверлей `rgba(15,17,21,0.6)`, без блюра (тяжёлый блюр выглядит дёшево).
- **Бейджи на фото авто** (Хит / Новинка): `rgba(15,17,21,0.72)` + текст белый + 4px радиус.

### Карточки автомобилей
**Форм-фактор:** прямоугольная, фото 16:10 сверху, метаданные снизу. Фон `--ink-100`, граница 1px `--ink-85`, радиус 8px. На hover — lift + усиление тени. Цена — крупно, акцентный цвет. Бейджи — abs позиционирование top-left.

### Слой защиты (protection gradient)
Когда поверх фото нужен текст (hero, CTA-блоки) — линейный градиент **снизу вверх** от `rgba(15,17,21,0.85)` до `rgba(15,17,21,0)`. Никогда — капсулы / pill backgrounds под текстом, всегда — градиент.

### Layout-правила
- **Sticky header**, всегда виден; высота 72px desktop / 56px mobile.
- **Sticky CTA bar** на мобильном внизу — телефон + «Подобрать авто».
- **Кнопка "Позвонить"** в header'е всегда заметна и не теряется при скролле.
- Никакой sticky/fixed-плашек кроме header и mobile CTA.

## Iconography

**Подход:** монолинейные SVG-иконки, **stroke 1.5px**, скругления 1px, размер 20px / 24px / 32px. Никакого fill-стиля для UI-иконок (только для специальных кейсов: звезды рейтинга, заполненный пин на карте).

### Источник
**Lucide Icons** (CDN-fallback, MIT-license) — это стандартный, чистый, монолинейный набор, идеально совпадающий с премиум-эстетикой. Подключение — статический CDN или локальные SVG в `assets/icons/`.

> ⚠️ **Substitution flag:** заказчиком не предоставлен корпоративный набор иконок. Lucide подобран как ближайшее визуальное соответствие премиум-минимализма. **Ask:** есть ли существующая библиотека иконок, либо подтвердить Lucide.

### Использование
- **Strokes only** для UI: меню, навигация, действия, фильтры.
- **Filled** допустимы только для:
  - Звёзды рейтинга (★)
  - Активный пин на карте
  - Чек-марки в чек-листах преимуществ
- **Размеры:** 16px (inline в тексте), 20px (кнопки), 24px (стандарт), 32px (фичер-блоки), 48–64px (иллюстративные большие иконки в секции «Как мы работаем»).
- **Цвет:** наследует currentColor; в премиум-блоках — `--ink-30`, в CTA — `--accent`, в бейджах — `--gold`.

### Эмоджи и юникод
- **Эмоджи запрещены** в интерфейсе.
- **Юникод-символы** — только функциональные: ★ (рейтинг), → ← (стрелки в навигации), ₽ (валюта).

### Логотип
Поскольку логотип не предоставлен, в `assets/logo.svg` собран **wordmark-плейсхолдер**: «ВОСТОК / АВТОИМПОРТ» в Bebas Neue с тонким золотым разделителем. Это рабочий вариант, требует замены на финальный лого.

### Флаги стран
SVG-иконки флагов Японии, Китая, Кореи лежат в `assets/flags/` — простые, плоские, 24×16. Используются для табов «по странам» в каталоге.

### Логотипы марок авто
Для карточек авто **не используются** логотипы брендов (Toyota, Hyundai и т.п.) во избежание визуального шума и copyright-вопросов. Название марки/модели — только текстом.
